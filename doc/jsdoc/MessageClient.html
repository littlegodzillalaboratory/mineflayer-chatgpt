    MessageClient

    Chat completion client wrapper. Builds the conversation payload, sends it to an OpenAI-compatible chat completion endpoint, and returns the reply with an inferred confidence score. Pointing `opts.baseURL` at a local server (e.g. a vMLX OpenAI-compatible endpoint) allows a local LLM to be used instead of OpenAI.
